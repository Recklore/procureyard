# ai-logs — raw AI session exports

One file per AI session used to build this take-home, exactly as exported by the
tool (no polishing/curation). Exports of the OpenCode session(s) used for the
implementation go here before submission.

- OpenCode: session exports from `~/.local/share/opencode/` (or via the UI/history)
- Claude Code: `~/.claude/projects/<project>/<session>.jsonl`
- Codex CLI: `~/.codex/sessions/<date>/rollout-*.jsonl`
- Cursor / Copilot / Gemini CLI / ChatGPT: their respective chat-export actions
